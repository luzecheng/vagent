# 机器人画风测试 · 检查结论（v1）

日期：2026-11-08　画图：Codex（`codex exec -s read-only`，姿势图用 `-i frames/00_设定图_v1_代码缩放.png` 作参考）

## 结论

**这种画风可以用于 vagent 的"生图 + 代码合成"流程。** 5 张图里同一个机器人保持得很一致：头盔、面罩、外壳分块、12 个冰蓝光点、线条质感都对得上；脚底几乎在同一条线上（偏差 ≤ 0.4%），水平位置基本居中。4 张姿势图都没有重画，也都不需要代码修正。

唯一的代码修正发生在设定图：原图机器人占画面高度 96.5%（要求约 80%），已等比缩小平移成 `00_设定图_v1_代码缩放.png`，并作为后面 4 张的参考图。

## 给后续流程的建议

1. **参考图固定用 `00_设定图_v1_代码缩放.png`**：这次 4 张都照着它的大小和位置画，说明参考图本身的构图会被继承。
2. **合成时用代码对齐**：每张图脚底和胸口核心 x 已能量出来，后期可按"脚底 y + 面罩线宽"自动缩放平移，把残余的 1–2% 偏差抹平，不用重画。
3. 扶膝、手指交叠这类手部细节是最容易出错的地方，以后有这种动作的镜头要重点放大检查。

# 第二轮（v2）：肩章、姿势图 v2、动态小样

日期：2026-11-08

## 肩章：放弃
- v2（照 v1 加肩章）：深色实心底 + 实心帆船，像贴纸，贴着关节 → 用户判不通过。
- v3：肩章改成线刻、跟随曲面、比关节暗，但整块肩甲的白色细线纹理没了，变成光滑深灰 → 不通过。
- v4（加三条限制）：纹理保住了，但帆船没了，只剩一个穿过肩关节的蓝色线圈，胸甲上多出蓝线 → 不通过。
- 用户决定放弃肩章，设定图沿用 `00_设定图_v1.png`。
- 经验：这种几十个像素的小细节，生图模型很难同时满足"保纹理 + 画准图形 + 避开关节"，以后小标识放到后期用代码叠加，或不做。

抽帧检查（`review/小样A_抽帧.png`、`review/小样B_抽帧.png`、`review/交叉淡化中间帧_v1v2对比.png`）：

- 第一版 04→00 的淡化中间帧出现**两个头、两个胸口核心**：04 v3 的头相对身体偏了约 20 像素。用 `review/fit_to_ref.py` 把 04 贴合到 00（11 个光点配对，求等比缩放 + 平移，残差平均 0.7px），v2 小样里这处重影消失，脚底仍对齐。
- 00↔01、01↔02、04→00（v2）、小样 B：只有动的那只手臂有半透明过渡，身体不重影，纹理没有突变。
- **02→03、03→04 仍有明显重影**：03 弯腰时头低了约 100 像素，整个上身位置都变了，交叉淡化必然出现两个头。贴合算法对 03 也无效（残差平均 30px），生成的 `03_弯腰挥手_v2_对齐_贴合.png` 没有使用。

## 结论
1. 画风和角色一致性：可用。
2. 交叉淡化只适合"身体大部分不动、只动手臂"的姿势切换（站→举手、站→叉腰、站→挥手）。
3. 身体整体位移大的切换（站 ↔ 弯腰）不能用简单淡化：正式做片时建议硬切、加一个很短的亮度过渡遮住，或者请 Codex 多画 1–2 张中间姿势。
4. 每张姿势图进合成前都先跑 `align.py` + `fit_to_ref.py`，能把剩余的位置偏差压到 1–2 像素。

## 抽帧检查明细
- 小样 A：第一版抽 8 帧（`review/小样A_抽帧.png`），v2 抽 8 帧（`review/小样A_v2_抽帧.png`），淡化中间帧放大对比在 `review/交叉淡化中间帧_v1v2对比.png`。
- 小样 B：第一版、v2 各抽 6 帧（`review/小样B_抽帧.png`、`review/小样B_v2_抽帧.png`），中间帧放大 `review/抽帧/B2_1.475s_放大.png`：只有正在举起的那只手臂半透明叠着，身体、头、关节完全重合，没有纹理突变。
- **只看过抽帧，没看过真正的动态**。切换是否自然（节奏、闪烁、淡化时的观感）要由用户看视频判断。

## 建议的下一步
1. 用户看小样 A_v2、小样 B_v2 的动态，判断淡化观感；如果"站 ↔ 弯腰"的重影不能接受，按结论第 3 条改成硬切或补中间姿势，再做一版小样。
2. 正式镜头的姿势清单定下来后，统一流程：Codex 照 `00_设定图_v1.png` 画 → `align.py` 对齐 → `fit_to_ref.py` 贴合 → 放大检查 → 合成。
3. 动态特效（光粒子、扫描线、发光闪烁、地面网格）按规矩全部留给代码做，下一轮可以在小样 B 上试一版。
